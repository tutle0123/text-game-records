# 바르도니아 연방 공화국 — 공통 세계관 안내

> 이 문서는 웹 기록관의 요약 참조본입니다. 본 게임의 확정 기준은 프로젝트의 「바르도니아_연방공화국_세계관_설정집.txt」 전문입니다. 게임별 유동 인물·사건은 각 게임의 state.json에 기록합니다.

- 수도 **그레이트베일**. 1940년대 소련풍 사회주의 일당독재국가. 각하는 실질적 최고지도자이며 5년마다 연임 찬반 국민투표를 실시합니다.
- 국가보안부는 각하 직속 특별기관입니다. 지휘계통은 **각하 → 국가보안부장 → 각 국장 → 각 과장 → 수사관·직원**입니다.
- 7개 국: 제1국 정치보안국, 제2국 국내방첩국, 제3국 대외정보국, 제4국 군사보안국, 제5국 특별경비국, 제6국 교정관리국, 제7국 통신정보국.
- 제1국의 과: 제1과 사상검열과, 제2과 사회감시과, 제3과 고발조사과, 제4과 정치수사과, 제5과 심문조사과, 제6과 기록관리과.
- 국가보안부 계급은 보안소위·보안중위·보안대위·보안소령·보안중령 등의 군사식 계급을 사용하고, 실제 호칭에서 '보안'은 생략합니다. 직책과 계급은 별개입니다.
- 기본 제복은 짙은 올리브그린, 붉은 띠 정모와 전용 표식. 경찰은 별도 조직이지만 국가보안부의 감독·특별 지휘 대상입니다.
- 중앙청사는 지상 6층·지하 2층. 제1국은 주로 2층, 심문실은 지하 1층, 중앙구금소는 지하 2층이며 중앙구금관리처가 운영합니다.
- 시민은 제복 직원이나 가까이 정차한 보안부 차량에 간단히 거수경례합니다. 지나가는 차량에는 경례 의무가 없습니다. '충성' 구호는 필요하지 않습니다.
- 기록장에 나오는 국가폭력, 구금, 수사는 폭력을 미화하지 않고 무감각하게 일상화된 권력 구조로 묘사합니다.
- 인물 이름·경력·인간관계는 개별 게임마다 새로 정합니다. 같은 세계관의 다른 게임이 자동으로 같은 사건과 인물을 공유하지 않습니다.
