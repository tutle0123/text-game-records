# 범용 게임 템플릿

새 게임은 `worlds/<world-id>/game-<일련번호>-<주인공슬러그>-<동명이인번호>/` 아래에 생성합니다. 예: `game-001-berezin-001`.

필수 구성:
- `index.html`: 공통 CSS/JS를 불러오는 게임 기록장 페이지
- `state.json`: 날짜와 시각, 현재 장면, 플레이어 프로필, 등장인물, 진행 업무, 미공개 세계 상태
- `history.json`: 시간 순으로 확정된 주요 사건
- 루트 `catalog.json`: 세계관 및 개별 게임 카드에 연결되는 항목

게임마다 고유 ID와 번호를 한 번만 발급합니다. 동일 이름의 새 캐릭터에도 별도의 끝자리 번호를 부여합니다. 게임 설정과 진행기록은 별도 게임끼리 복사하지 않습니다.

`state.example.json`은 필드 구조 예시입니다. HTML을 표시할 때는 기존 바르도니아 기록장 index.html의 공통 스크립트를 재사용하거나 새로운 세계관 테마를 추가합니다. 미래 게임의 디자인은 해당 시대와 문화에 맞춰 별도로 조정합니다.
