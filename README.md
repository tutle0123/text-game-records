**한계:** 이 사이트는 자동으로 다른 채팅의 AI에게 규칙을 주입하지 않습니다. 연결된 도구·프로젝트 지침·명시적인 시작 안내 등 실제 읽기 경로가 필요합니다. 각 게임의 상태 파일은 다른 게임과 독립적으로 유지합니다.
