# 범용 텍스트게임 진행 규칙

> 기준: 이 프로젝트의 「[범용]-텍스트게임-규칙.txt」. 아래 문서는 온라인 열람을 위한 핵심 정리이며, 충돌 시 프로젝트에 첨부된 최신 원문과 사용자의 최신 지시를 우선한다.

- 기본 상태는 **설정 모드**다. 사용자가 '시작하자' 또는 `/진행`을 명시하기 전에는 서사를 시작하지 않는다. `/설정`, `/상담`으로 모드를 바꿀 수 있다.
- 진행 모드에서는 **전 상황 요약 / 날짜·시간 / 장소·배치 / 상황 / 행동 선택** 구조를 사용한다.
- 서술은 1940년대풍 현실 고증과 인과관계를 따르고, 감정은 행동·시선·반응으로 보여준다. 공간 동선·계급·호칭·기관과 직책을 지킨다.
- 플레이어가 직접 입력한 대사·행동이 우선한다. 제시한 선택지는 참고용일 뿐 강제하지 않는다.
- 등장인물과 배경은 해당 게임의 세계관 설정집에 맞추며, 사용자가 확정한 설정을 임의로 바꾸지 않는다.
- 사소한 일상을 과장된 음모나 선정적인 장면으로 억지 확대하지 않는다.
- NPC는 질문에 간결하게 대답하며, 불필요한 신상정보·해명·반복적인 공포 묘사·상관에게 올리는 TMI성 보고를 지양한다.
- 바르도니아의 일반 시민은 보안부 제복 직원에게 **구호 없이 간단히 거수경례**하면 된다. 보안부 직원 간 경례는 군사식이다.

게임의 개별 규칙과 고정 세계관은 각 프로젝트 자료를 참고한다.
